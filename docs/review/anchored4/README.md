# Anchored dough pull review

The owner chose an anchored rounded teardrop, face on the plump part with eyes following the finger, and a quick recoil with two soft decaying jiggles. This build implements a localized shader deformation of the actual skinned meshes instead of whole-character widening. GLB source meshes and the palette are unchanged. Shader uniforms operate per bun; normals receive an approximate deformation correction, facial details share a rigid displacement and the underlying face region follows them. The base Body transform retains a unit determinant, but the localized silhouette deliberately gains volume: its determinant test is not a whole-mesh volume measurement.

`actual-pointer-pull.webp` contains 58 actual mouse-driven Chromium frames at a 390 × 844 viewport, advanced in 1/30-second steps. `pull-comparison.png` compares the retained previous build with the new build under the same strong horizontal, vertical and diagonal inputs. The other sheets show real release and both merge tiers, with enlarged crops for inspection. Some crest/hop edges extend outside the detail crops; the full phone frames retained by `tactile_review.py` include the board. The movie was recaptured after removing a duplicate overlay ring that crossed the face.

Visual inspection caught and corrected buried facial details, overly small effort expressions, three-face merge overlap, static gather targets behind a moving merged bun, and the face-crossing overlay. The final pair compresses toward the current merged-bun position for a short contact beat, then the resulting tier appears at a readable size, hops and lands. Launch physics remains immediate. The camera default remains 45°.

Validation: 50 Node behavioral tests passed, including all six solved routes and 30/60/120 render schedules. `character_review.py` checked actual shader reference anchoring, opposite/vertical/diagonal pulls, reversal/cancel, diagonal Body matrix cross-terms, both merges and browser shader errors. `tactile_review.py` captured 48 before and 48 after phone frames; `animation_sequence.py` captured 38 action/win frames. `pointer_feedback.py` passed mouse launch, emulated touch cancellation and pause cancellation; `progression_browser.py` passed win/save/next/trail/reload. `motion_consistency.py` compared rig state and localized field uniforms at 30/60/120 schedules. `recovery_browser.py` found a bone-texture leak and then passed after per-clone skeleton disposal, verifying stable resource counts across repeated merge Undo, gentle motion and Retry.

These are actual desktop Chromium WebGL captures and emulated phone inputs, not physical-phone performance, battery or tactile evidence. The user must judge the revised feel through play. The larger color/shine study remains deferred.
