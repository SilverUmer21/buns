# Bunbreak · Sunshine Kitchen

A bright 3D flick-and-merge puzzle with round, expressive buns.

Development is proceeding in small patches: reliable downloads, cited research and GDD, reproducible asset sources, the Godot runtime, then game-feel and interface improvements with tests.

The repository is being populated incrementally. Current local baseline: one playable puzzle with 48 headless gameplay checks; rendered in-engine review and Android packaging remain to be verified. Download links and validation evidence will be added as each stage is ready.
